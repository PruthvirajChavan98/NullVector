# Create ADR Workflow

1. Read `docs/adr/0000-adr-template.md` to understand the required structure.
2. List the files in `docs/adr/` to determine the next available sequential number (e.g., if `0002` exists, use `0003`).
3. Ask the user for a brief title/description of the decision.
4. Create a new file named `XXXX-[brief-title].md` in the `docs/adr/` directory.
5. Populate the file with the template structure, setting Status to `proposed` and Date to the current date.
6. Ask the user for the Context, Decision, and Consequences to fill in the document.
